🎨 Sistema de Cadastro de Cores
Projeto desenvolvido em Java com integração ao MySQL para cadastrar, listar e buscar cores pelo código HEX.

# Tecnologias
Java 17+
MySQL
JDBC
Maven

# Funcionalidades
Cadastro de cores comuns e especiais.
Listagem de cores cadastradas.
Busca por código HEX.
Herança e Programação Orientada a Objetos.

# Como executar
Execute o script sql/banco.sql no MySQL.
Configure a senha do banco em Conexao.java.
Abra o projeto no IntelliJ IDEA.
Execute a classe Main.java.

# Objetivo
Projeto de estudo para praticar Java, POO e integração com banco de dados.
